LinuxLab

Free browser-based Linux sandbox

Built by Pratik Mule · Nexvelor

LinuxLab is a free Linux sandbox that runs in the browser. Pick an operating system and practice in a terminal.

Features

  • Choose an OS to start a lab session
  • 1 hour free session with a countdown timer
  • Open more OS sessions in tabs
